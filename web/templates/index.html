About This Tool

This tool allows you to scrape job listings from Djinni.co, a Ukrainian job board for IT professionals. The scraper:

  • Extracts job details including title, company, salary, and requirements
  • Translates job information from Ukrainian to English
  • Stores data in a searchable database
  • Operates asynchronously to keep the web interface responsive
