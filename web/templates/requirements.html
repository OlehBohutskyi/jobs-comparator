About This Tool

This tool helps you understand common requirements for jobs in specific domains by:

  • Analyzing the text of up to 100 job listings in each selected domain
  • Performing frequency analysis to identify the most common terms
  • Using AI to generate a comprehensive summary of typical requirements
  • Optionally comparing with educational programs to identify improvement areas

Note: Custom stop words can be edited in the "stop_words.txt" file at the app root to improve analysis quality.

Troubleshooting

If you encounter issues with the analysis:

  1. API Key: Make sure your OpenAI API key is properly set in the .env file with no quotes or spaces
  2. Stop Words: Edit stop_words.txt to improve word frequency quality
  3. Test Connection: Test OpenAI API connection
